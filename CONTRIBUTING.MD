# Contributing to KraftNow

Thanks for your interest in contributing!

## Getting started

1. Fork and clone the repo
2. Install dependencies: `npm install`
3. Run the dev server: `npm run dev`

## Guidelines

- Keep components simple and consistent with existing patterns
- Use TypeScript for all new code
- Run Prettier before committing: `npx prettier --write .`

## Reporting issues

Open a GitHub issue with a clear description and steps to reproduce.

## Pull requests

- Keep PRs focused on a single change
- Describe what you changed and why
